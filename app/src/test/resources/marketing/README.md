# Marketing fixture provenance

`petdex-teknium-idle.png` is the first 192x208 idle cell extracted without
resampling from Petdex's immutable Teknium spritesheet:

- Petdex entry: https://petdex.dev/pets/teknium
- Source asset: https://assets.petdex.dev/pets/teknium-764590a21410/sprite.webp
- Catalog credit: `asimons81`
- Source spritesheet: 1536x1872, arranged as 8x9 cells

The pinned frame keeps Roborazzi screenshots offline and deterministic while
rendering the real Petdex artwork through Hermes-Relay's production
`PetAvatar` and `FloatingPetCompanion` components.
