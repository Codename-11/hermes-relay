v1.18.1 - Reliable browser sign-in

Summary
* Dashboard browser sign-in stays connected while you complete the provider flow and return to Hermes-Relay. Callback pages show which provider handled the attempt.

Highlights
* Finish browser sign-in — The app keeps the sign-in callback and session check connected while the browser is open, then ends the sign-in notification when the attempt finishes or is canceled.

Improved
* Recognize the sign-in provider — Browser callback success and error pages identify the selected provider and use guidance that applies to self-hosted and hosted Hermes.

Compatibility
* Browser sign-in continues to use upstream Hermes Dashboard; no Hermes-Relay Plugin update is required.
